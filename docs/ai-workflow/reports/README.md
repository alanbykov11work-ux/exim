# Отчёты реализации

Путь отчёта: `docs/ai-workflow/reports/<TASK-ID>/`.

Разрешённые файлы исполнителя:

- `submission-NN.md`;
- `evidence-manifest-NN.md`;
- `blocker-NN.md`;
- `addendum-NN.md`.

Файлы `review-NN.md` создаёт только независимый reviewer. Файлы `acceptance-NN.md` создаёт только владелец продукта или назначенный им человек.

Нельзя включать secrets, credentials, cookies, `.env`, реальные персональные данные или unrestricted Preview links.
