# EXIM Super App — как запустить

Ветка: `task/TASK-2026-001-integrated` (draft PR #8)
Коммит указан в `git log`; архив проекта собирается командой `git archive HEAD`.
В репозитории нет `node_modules`, `.next`, паролей, токенов и `.env`.

## 1. Требования

- Node.js 22 и npm 10.
- Отдельный **тестовый** проект Supabase (не production) — для запуска приложения.
- Для локального стенда без Supabase: PostgreSQL 16, PostgREST 12, Playwright с Chromium.

## 2. Переменные окружения

```
cp .env.example .env.local
```

| Переменная | Где взять |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API → Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase → Project Settings → API → anon public key |

`NEXT_PUBLIC_BUILD_TS` выставляется автоматически в `next.config.mjs`. Других переменных приложение не читает.
`.env.local` в Git не коммитить.

## 3. Установка и проверки

```
npm ci
npm test            # 90 тестов (SQL/RLS в PGlite, роутер, загрузчик, preflight)
npm run typecheck
npm run lint
npm run build       # нужны переменные из п.2 (для проверки сборки подойдут фиктивные)
npm run dev         # http://localhost:3000 → /login → /app
```

## 5. Локальный стенд без Supabase (PostgreSQL 16 + PostgREST 12)

Скрипты отказываются работать, пока вы явно не подтвердите одноразовую локальную базу:

```
export EXIM_DISPOSABLE_CONFIRM=yes-disposable-local-instance
export PG_ADMIN_URL="postgresql://postgres@/postgres?host=/tmp&port=5432"   # только локальный сервер, БД postgres
export POSTGREST_BIN=/path/to/postgrest
scripts/local-stack/reset-and-run.sh        # новая БД, все миграции, 7 аккаунтов, REST-сценарий (85 проверок)
scripts/local-stack/rollback-rehearsal.sh   # репетиция отката через резервную копию
PW=/path/to/playwright SUPABASE_UMD=/path/to/supabase.js scripts/local-stack/real-ui.sh   # SPA в браузере (18 проверок)
npm run test:e2e                            # браузер с подменённым backend (20 проверок)
```

Хосты Supabase и любые удалённые адреса эти скрипты отклоняют.
